# sushi-rating

A simple sushi rating website where users can rate sushi items, add new rolls, and see the best-rated sushi.

## What is included

- `index.html`: main website page
- `styles.css`: responsive styling
- `script.js`: interactive rating, local storage, and sushi management

## Run locally

1. Open `index.html` in your browser.
2. Optionally host with a local static server:
   - `npx http-server` (if Node.js is installed)
   - or `python3 -m http.server 8000`
